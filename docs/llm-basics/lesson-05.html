LESSON 05 / 06

模型如何从错误中学习

预训练、损失与参数更新
本课目标　文本提供预测目标，损失衡量偏差，梯度指导参数更新；验证集检查泛化。

01 / 把文本变成监督信号

语言模型可以从文本自身构造预测目标，不必给每句话额外手写标签。例如一串 token 是 A、B、C、结束，模型会在相应位置学习预测 B、C、结束。

输入：A   B   C
目标：B   C   结束

这里表示训练样本的对齐关系；实际实现可能传入同一序列，由损失函数内部移动标签。因果遮罩仍然必要，防止当前位置看到未来目标。

02 / 用损失衡量预测错误

交叉熵会惩罚模型给正确目标分配过低的概率。单个目标的损失可以写为 L = −ln p(正确 token)。概率越高，损失越小。

例如正确 token 概率为 0.5，损失约为 0.693；概率为 0.1，损失约为 2.303。这里使用自然对数。训练通常会对许多有效位置的损失求平均。

03 / 反向传播与优化器

反向传播计算损失对参数的梯度，优化器再根据梯度调整参数。一个简化的更新式是 新参数 = 旧参数 − 学习率 × 梯度；常用优化器还会利用额外统计量。

预测→损失→梯度→更新参数

学习率控制每次更新的尺度。更大的更新不一定带来更好的学习，过大可能使训练不稳定。

04 / 预训练之后，还有哪些训练

预训练从大量文本学习通用预测规律；指令微调用任务与回答示例教模型按指令回应；偏好优化等方法进一步调整回答行为。它们的目标与数据组织方式不同。

评估需要使用未参与训练的数据。训练损失下降只说明模型更适应训练数据，不能单独证明它在新任务上更可靠。数据质量、重复和污染都会影响判断。

模型怎样知道词语顺序

位置编码与 RoPE 的直觉
本课目标　位置机制提供顺序线索；RoPE 通过旋转 Q、K 引入位置关系。

01 / 词相同，顺序不同，意思就不同

“小猫追小狗”和“小狗追小猫”使用相似的词，角色关系却发生变化。基础注意力的内容匹配本身缺少明确的位置坐标，因此模型需要位置相关机制。

因果遮罩限制可见范围，但它不等同于完整的位置编码。位置机制帮助模型表达 token 在哪里、彼此相隔多远。

02 / 一种方案：在输入中加入位置向量

绝对位置编码为第 0、1、2……个位置提供不同向量，再与 token 表示结合。这些向量可以按固定公式生成，也可以由训练学习。

这样，同一个 token 出现在不同位置时，进入后续网络的表示就会不同。绝对位置编码是位置机制的一类，不是所有模型都采用它。

03 / RoPE：让位置进入旋转

RoPE（旋转位置编码）把 Q、K 向量的成对维度按位置旋转，不同维度对使用不同旋转频率。旋转后做内积，匹配分数就会包含相对位置的信息。

一个二维分量的旋转：
x′ = x cos θ − y sin θ
y′ = x sin θ + y cos θ
角度 θ 随位置变化。

直观上，比较两根旋转后的指针时，它们的相对角度与位置差有关。实际向量包含许多这样的维度对，而不是只用一根指针。

04 / 为什么长上下文仍然困难

位置公式能够计算很大的位置，不代表模型在远超训练长度的文本上仍然可靠。位置分布、训练数据、注意力开销和任务难度都会影响表现。

长度外推技术会调整位置机制等设计，但“能输入更长”与“能可靠利用所有内容”是两个不同的评价目标。

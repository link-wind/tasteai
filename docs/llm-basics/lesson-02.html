LESSON 02 / 06

文字怎样变成数字

Token、编号与 Embedding
本课目标　Tokenizer 负责文本与编号的转换；Embedding 负责编号到可训练向量的映射。

01 / 第一步：切成 token

计算机不能直接把一句话的意义送入神经网络，需要先把文本编码。Tokenizer 按特定规则，把文本变成一串 token 编号。实际切分依赖 tokenizer，中文字符也可能对应多个 token。

字符级方法词表较小但序列可能较长；整词级方法容易遇到未收录的词。子词方法在词表规模和序列长度之间折中。

02 / BPE 在做什么

BPE（字节对编码）的一种基本思路是：从较小单位开始，统计训练文本中相邻单位对的频次，反复把高频对合并成新单位。训练后，编码器使用学到的词表和合并规则切分文本。

教学示例：l o w → lo w → low
真实结果取决于训练语料和合并规则。

字节级 BPE 从字节表示出发，配合适当实现可以覆盖任意文本。BPE 学的是压缩式的切分规律，不是人工规定的语法或词义边界。

03 / 第二步：编号查向量

Token 编号只是词表中的索引。例如编号 42 并不意味着比编号 21“语义大两倍”。Embedding 会把编号映射成一组可训练的数值，也就是向量。

编号序列：[12, 42, 7]
Embedding 表：V 行 × d 列
查表后形状：[3, d]

V 是词表大小，d 是向量维度。向量会随训练调整；经过后续网络后，每个位置的表示还会结合上下文发生变化。

04 / 把这条链路连起来

文本→Tokenizer→token ids→向量序列

Tokenizer 与模型需要匹配：同一个编号在不同词表里可能对应不同文本。更换 tokenizer 后，不能假定旧模型仍能正确理解编号。

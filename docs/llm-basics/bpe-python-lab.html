提示与参考


提示 1：先检查有没有下一项
在访问 ids[i + 1] 前，确认 i + 1 < len(ids)。


提示 2：为什么匹配后要前进两项？
aaa 的相邻对出现两次，但中间的 a 只能用一次。左到右合并得到 aa | a，不是两个 aa。

from collections import Counter


def count_pairs(corpus):
    counts = Counter()
    for row in corpus:
        for pair in zip(row["ids"], row["ids"][1:]):
            counts[pair] += row["weight"]
    return counts


def merge_pair(ids, pair, new_id):
    """左到右合并；每个输入位置最多使用一次。"""
    out = []
    i = 0
    while i < len(ids):
        if i + 1 < len(ids) and (ids[i], ids[i + 1]) == tuple(pair):
            out.append(new_id)
            i += 2
        else:
            out.append(ids[i])
            i += 1
    return out

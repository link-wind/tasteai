LESSON 01 / 06

大模型在计算什么

从一次接龙，看懂语言模型
本课目标　生成由多次下一 token 预测组成；训练更新参数，推理使用参数。

01 / 先认识它的基本任务

常见的 GPT 类语言模型会根据已有文本，预测下一个 token。Token 是文字片段，可能是字、词的一部分或标点。先不要把它固定理解为一个汉字。

例如“今天下雨了，出门记得带”后面，“伞”往往比“太阳”更合理。模型不是直接输出一句完整答案，而是先计算下一 token 的候选分数，再把分数转换成概率。

02 / 一段回答是怎样长出来的

选出一个 token，把它接到原文后，再用更新后的上下文预测下一个。反复执行，就形成长回答。这叫自回归生成。遇到结束标记或达到长度上限时，生成停止。

已有文本→候选概率→选一个 token→接回文本

生成规则可以选择最高概率候选，也可以按概率抽样，所以同一问题可能得到不同回答。

03 / 训练与推理，各做什么

过程做的事情参数是否改变
训练预测、计算误差、更新参数通常会
推理用已有参数计算并生成普通聊天通常不会

参数是训练得到的大量数值。上下文是这次输入给模型的内容。你在对话里提供新信息，可能改变回答，但这不等于模型的参数被更新。

04 / 为什么流畅不等于正确

语言建模直接优化的是预测表现，并不自动核验每一个事实。因此模型可能生成听起来合理、实际却错误的内容。检索、工具调用和人工核验可以提供额外证据，但不能让错误风险自动归零。

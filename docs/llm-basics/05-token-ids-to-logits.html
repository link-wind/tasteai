从 token ids 到 logits

把 model(input_ids) 打开，跟着一个小批次走完整条链路。

本课要点与先修

  • 解释 decoder block 中注意力、前馈网络、归一化和残差各自做什么。
  • 分清训练时的标签移位与推理时的最后位置采样。

先固定一个能手算的输入契约

设 B=2、T=4、V=32、D=16。输入 [2,4] 的整数 IDs，输出 [2,4,32] 的 logits，每个位置为下一 token 提供 32 个分数。

ids = torch.tensor([[1, 2, 3, 4], [5, 6, 7, 8]])
# ids.shape == (2, 4)，dtype 为整数
logits = model(ids)
# logits.shape == (2, 4, 32)

ID 必须位于 0～31。本课 TinyLM 随机初始化，用于验证接口，不具备已训练的语言能力。

batch 内样本独立；注意力在各自序列内部计算。本例等长，无 padding。

沿形状走一遍前向传播

Embedding 查表为 [B,T,D]；decoder blocks 更新表示但保持形状；最终归一化后由 LM Head 映射到 [B,T,V]。

阶段本例形状作用
input_ids[2,4]离散编号
Embedding[2,4,16]编号查向量
2 个 decoder block[2,4,16]融合允许的上下文并变换特征
最终 RMSNorm[2,4,16]调整数值尺度
共享 LM Head[2,4,32]每个位置产生词表分数

D 是隐藏维度，V 是候选词表维度；logits 经 softmax 才是概率。

Decoder block 内部：先混合位置，再变换特征

采用 pre-norm：归一化后进入子层，再把子层输出加回残差流。

a = x + Attention(RMSNorm(x))
y = a + FFN(RMSNorm(a))

Attention 汇总不同位置；FFN 对每个位置独立变换特征，共享同一组参数。

RMSNorm 按均方根归一化并学习缩放；残差将子层增量加回输入。

def forward(self, x):
    x = x + self.attention(self.norm1(x))
    n = self.norm2(x)
    x = x + self.down(F.silu(self.gate(n)) * self.up(n))
    return x

SwiGLU 将 gate 与 up 分支逐元素相乘，再由 down 投回 D 维，保证可与残差相加。

为什么训练已知整段文本，也不能偷看未来？

位置 i 的目标是下一 token；因果遮罩屏蔽未来键 j>i，避免训练时看到答案。

训练能并行计算已知文本的所有位置；生成仍需逐步选出下一 token。

位置 0：可见 0
位置 1：可见 0、1
位置 2：可见 0、1、2
位置 3：可见 0、1、2、3

验证因果性：只修改最后一个输入，前面位置的 logits 应不变（固定参数、无 dropout）。

训练：logits 与目标错开一个位置

输入 [1,2,3,4] 的前三个位置学习预测 [2,3,4]；本样本没有提供最后位置的目标。

pred = logits[:, :-1, :]   # [B, T-1, V]
target = ids[:, 1:]        # [B, T-1]
loss = F.cross_entropy(
    pred.reshape(-1, pred.shape[-1]),
    target.reshape(-1),
)
loss.backward()

Cross entropy 直接接收 logits 与整数标签，不先做 softmax。

数据管线与模型内部只做一次标签移位。

推理：取最后有效位置，但不等于只有它有输出

生成时取最后有效位置的 logits，选择 token、接到尾部，再继续。KV cache 可复用历史计算。

with torch.no_grad():
    logits = model(ids)
    next_ids = logits[:, -1, :].argmax(dim=-1)
    extended = torch.cat([ids, next_ids[:, None]], dim=1)

以下为无 padding 的贪心示例；有 padding 时需找到最后有效位置，不能直接照搬 [:,-1]。

练习

自测与解析 · 6 题

先作答，再展开解析。

01 · 本例输出 [2,4,32] 的三个维度分别是什么？

展开逐步解析

2 条独立样本、每条 4 个输入位置、每个位置对 32 个词表类别的分数。最后一维不是隐藏维度；Embedding 与 block 使用的是 D=16。

02 · 为什么 FFN 能对每个位置独立计算，却仍能利用上下文？

展开逐步解析

它接收到的是注意力更新后的表示，里面已经汇总了其他允许位置的信息。FFN 这一子步骤按位置变换特征，不需要再次直接混合序列位置。

03 · 输入 [1,2,3,4]，用于本例损失的目标是什么？

展开逐步解析

[2,3,4]，对应 logits 的前 3 个位置。最后位置没有已知下一项目标，所以示例中不参与损失。不能把 [1,2,3] 当成目标。

04 · 为什么 cross_entropy 前不必手动 softmax？

展开逐步解析

该函数接收未归一化分数，并在数值稳定的实现中处理对数 softmax 与负对数似然。先转概率会改变输入语义，通常导致错误目标。

05 · 只更改最后一个输入，前缀输出应否变化？

展开逐步解析

本课确定性因果模型中不应变化。前缀位置无法看到未来 token；测试会比较改动前后的前 T-1 个位置，帮助发现遮罩错误。

06 · 真实 tokenizer 的编号 9906，能送进本例 V=32 模型吗？

展开逐步解析

不能，超出了 0～31 的索引范围。即使某个编号数值不越界，若词表含义不匹配，语义仍然错误。

模型怎样利用上下文

Transformer 与 Self-Attention
本课目标　Attention 汇总上下文；因果遮罩阻止偷看未来；LM Head 把隐藏向量变成词表分数。

01 / 把 Transformer 看成一条加工线

向量进入多层 Transformer。常见的 Decoder-only 层包含 Attention、前馈网络、归一化和残差连接。Attention 在位置之间交换信息，前馈网络对每个位置的表示做进一步变换。

残差连接把模块的输入加回输出，帮助信息和梯度沿深层网络传播。归一化帮助控制数值尺度。不同模型的具体组件与顺序可以不同。

02 / Attention：此刻应该参考哪里

读“猫躲进箱子，因为它害怕了”，“它”的表示需要利用前面相关信息。Attention 会为允许参考的位置计算权重，再对那些位置的值向量做加权组合。

Q（Query）可类比为当前位置发出的查询；K（Key）用于匹配；V（Value）提供被汇总的信息。它们通常来自输入表示的可训练线性变换，并非人工填写的语言规则。

Attention(Q,K,V) = softmax(QKᵀ / √dₖ + mask)V

先算匹配分数，按 key 的维度缩放，再应用遮罩、转换成权重，最后汇总 V。这里的比喻用于理解数据流，不表示模型真的形成了人的意图。

03 / 为什么不能偷看后面的答案

自回归语言模型使用因果遮罩：位置 i 可以参考自己和前面的有效位置，不能参考后面的位置。否则训练时可以直接看到待预测的文本，而生成时却没有这些信息。

训练时，已知整段文本，可以用遮罩并行计算多个位置的预测；生成时，新 token 依赖上一步结果，通常逐步产生。

04 / 多头与输出

多头注意力让模型在多个表示子空间中计算注意力，再合并结果。不要把每个头固定理解为“语法头”或“事实头”；实际功能需要分析验证。

最后，每个位置的隐藏向量经 LM Head 映射为词表大小的 logits（未归一化分数），再用于计算概率或训练损失。
